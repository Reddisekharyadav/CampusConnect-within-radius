# CampusRadius Browser Extension

A browser extension (Manifest V3) for Chrome, Edge, and Firefox that brings CampusRadius — the privacy-first campus discovery app — directly to your browser toolbar.

## Structure

```
extension/
├── manifest.json          ← MV3 manifest (Chrome, Edge, Firefox)
├── popup.html             ← Popup shell (loads the React app from dist/)
├── background.js          ← MV3 service worker
├── options.html           ← Settings page (configure backend URL)
├── options.js             ← Options page logic
├── icons/
│   ├── icon16.svg
│   ├── icon48.svg
│   └── icon128.svg
└── dist/                  ← Built React app (generated by `npm run build:extension`)
```

## Build

```bash
# From the project root:
npm run build:extension
```

This runs Vite with `vite.extension.config.ts` and outputs the React app to `extension/dist/`.

## Load in Chrome / Edge (Unpacked)

1. Run `npm run build:extension`
2. Open Chrome and go to `chrome://extensions`
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked**
5. Select the **`extension/`** folder (not `extension/dist/`)
6. The CampusRadius icon appears in your toolbar — click it!

## Load in Firefox

1. Run `npm run build:extension`
2. Open Firefox and go to `about:debugging#/runtime/this-firefox`
3. Click **Load Temporary Add-on…**
4. Select `extension/manifest.json`

> **Note:** Firefox requires extensions to be re-loaded each browser session when loaded as temporary. For permanent installation, the extension must be signed via AMO.

## Configure Backend URL

Click the extension icon → Settings (gear icon) or right-click the extension → Options to set your backend URL:

- **Local development:** `http://localhost:5000`
- **Production (Cloud Run):** `https://campusradius-backend-xxxxx.a.run.app`

## Permissions

| Permission | Why |
|---|---|
| `geolocation` | To detect nearby users |
| `storage` | To save your backend URL setting |
| `http://localhost:5000/*` | Local development backend |
| `https://*.run.app/*` | Cloud Run production backend |
